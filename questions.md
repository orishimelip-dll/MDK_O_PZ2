1 - Из чего состоит программа на языке Python?
Программа на Python состоит из модулей.  Модули состоят из операторов, которые могут содержать выражения, функции, классы и объекты. Код выполняется интерпретатором сверху вниз.

2 - Операторы условия и выбора на языке Python?
В Python не было классического switch/case до версии 3.10, где появился match/case. Основной оператор выбора - конструкция if-elif-else.

3 - Операторы цикла на языке Python?
Используются циклы:
- for для итерации по последовательностям: спискам, строкам, диапазонам range()
- while выполняется, пока условие истинно.
Для управления циклами используются break и continue.

4 - Функции на языке Python?
Функции объявляются с помощью ключевого слова def. Они могут:
- принимать аргументы (позиционные, именованные, *args, **kwargs)
- возвращать значения через return.
Также есть анонимные функции lambda.

5 - Исключения на языке Python?
Это механизм обработки ошибок. Используется конструкция try-except-else-finally. Исключения можно вызывать вручную с помощью raise. В Python множество встроенных исключений.
